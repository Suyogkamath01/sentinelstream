# Screenshot checklist

No screenshots are committed as completed evidence. Capture these screens only
after the corresponding service has actually been started:

- dashboard overview and KPI cards
- live transaction stream
- fraud alert investigation with explanation
- SHAP or deterministic explanation details
- FastAPI Swagger UI
- Kafka UI topic list and a sample message
- MLflow experiment/model metadata
- Prometheus targets and metrics
- Grafana system/fraud dashboard
- Evidently or deterministic drift report
